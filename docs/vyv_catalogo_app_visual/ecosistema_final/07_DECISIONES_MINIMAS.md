# Decisiones Mínimas - RPG y Ecosistema Veta & Vigor

1. **Rutas vs Sistemas:** ¿El concepto proyectado de "Rutas y Maestrías" (ej. "Tu Primera Dominada") vivirá *dentro* de la pestaña de Sistemas, o requerirá su propia sección exclusiva en la UI para no chocar con las rutinas diarias?
2. **Arte Evolutivo:** El "Árbol de la Forja" actual usa Emojis nativos (Brote, Joven, Roble, Mundo) y animaciones CSS (Ánima del bosque). ¿Deseas reemplazar estos emojis por ilustraciones en 2D oficiales y vectores?
3. **Muro de Fama (Naming):** En el front-end actual y base de datos se llama "Muro de Fama". ¿Cuál es el nombre definitivo para los mockups: "Muro de Fama", "Atleta del Mes" o "Atleta Vigor de la Temporada"?
4. **Economía de Lanzamiento:** Las misiones otorgan 5 monedas de forja. ¿Mantenemos este ratio para el MVP o necesitas ajustar la inflación/desflación de inmediato antes de lanzar?
5. **Cosméticos:** ¿Podemos lanzar el MVP exclusivamente con los 3 ítems actuales (Ficha, Borde, Ánima), o es indispensable agregar "Fondos de Perfil" antes del despliegue oficial?
